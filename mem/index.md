# Project Memory

## Core
- UI language is Arabic (RTL). Dark professional theme.
- All design work MUST follow DESIGN_RULES.md in repo root: one accent colour, no gradients (esp. blue→purple), no gradient text, no shadows on non-floating elements, no sparkle icons, no emoji as UI, no icon containers, no em dash in copy, no banned hype words, no hover glow/lift/scale, no eyebrow badges, sizes constrained (headline ≤56px, buttons 36–44px, section padding ≤96px), 4px spacing scale, semantic HTML.
