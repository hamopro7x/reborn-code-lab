# تحكم كامل في طرق الدفع

## النتيجة
تتحكم كل طريقة دفع في شكل تفاصيلها من لوحة الإدارة، بدل ربط العرض باسم Binance أو افتراض أن كل الطرق عملات رقمية.

## التنفيذ
- إضافة اختيار **نوع العرض** لكل طريقة: تحويل محلي، محفظة إلكترونية، تحويل بنكي، أو عملات رقمية.
- إضافة حقول قابلة للتعديل لعناوين البيانات المعروضة، مثل: «رقم المحفظة»، «رقم الحساب»، «عنوان الشبكة»، و«اسم البنك/الشبكة».
- إضافة مفاتيح لإظهار أو إخفاء: اسم الحساب، التعليمات، والمبلغ المطلوب.
- جعل رقم الحساب اختياريًا عند إنشاء طريقة لا تحتاجه.
- ربط صفحة الدفع بهذه الإعدادات مباشرة، بدون اكتشاف النوع من الاسم.
- إبقاء الأيقونة والدولة والترتيب وحالة التفعيل كما هي.

## التفاصيل التقنية
- توسيع جدول طرق الدفع بحقول إعداد العرض، مع قيم افتراضية تحفظ توافق الطرق الحالية.
- تحديث العرض العام الآمن وتفاصيل الطريقة المختارة لإرسال الإعدادات اللازمة فقط.
- تحديث نموذج الإدارة وبطاقات المعاينة، ثم تحديث جزء طريقة الدفع فقط.
- فحص الأنواع المختلفة والتأكد أن الحفظ والعرض يعملان دون تغيير إنشاء الطلب أو رفع الإثبات.
