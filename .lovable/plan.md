# إصلاح فحص نشر Fly

## التغيير
- جعل فحص `mag-pro1.com` يتحمل انقطاع HTTP المؤقت أثناء استبدال أجهزة Fly بدل إنهاء السكربت فورًا.
- انتظار استقرار الإصدار الجديد وإعادة المحاولة بمهلة أطول، مع استمرار التحقق من رقم البناء وعدم وجود الحزمة القديمة.
- إبقاء التطبيق المستهدف `m-hamo` والنطاق والمفاتيح وآلية النشر دون تغيير.

## التحقق
- فحص صياغة سكربت PowerShell والتأكد أن أخطاء الاتصال المؤقتة تدخل دورة إعادة المحاولة.
