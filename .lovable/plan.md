# صورة شبكة مستقلة للعملات الرقمية

## التنفيذ
- إضافة حقل «صورة الشبكة» يظهر في نافذة طريقة الدفع عند اختيار «عملات رقمية» فقط.
- استخدام نفس رفع الصور الحالي، مع إبقاء صورة طريقة الدفع وصورة الشبكة منفصلتين.
- عرض صورة الشبكة بجانب اسم الشبكة بعد اختيار وسيلة الدفع الرقمية.
- تحديث ملف SQL لإضافة حقل الصورة وإرجاعه ضمن تفاصيل وسيلة الدفع.

## النطاق
لن يتغير تصميم أو سلوك طرق الدفع غير الرقمية، ولن تتغير أي صفحة أخرى.

## ملاحظة
بعد التنفيذ يلزم تشغيل ملف تحديث طرق الدفع في SQL Editor مرة أخرى لتفعيل الحقل الجديد.
